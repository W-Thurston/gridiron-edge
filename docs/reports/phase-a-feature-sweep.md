# Phase A feature sweep - 2026-09-29

Consolidated incremental walk-forward sweep of the wired feature batches (`DECISIONS.md` D62). Generated by `gridiron evaluate feature-sweep`; a dated record, not an input to any pipeline.

## Protocol

- Steps: baseline (schema 5 composition), then each batch cumulatively in wiring order; each batch is scored against the step before it.
- Rows: matched. Every step and family is scored on identical games: rows complete on the widest feature set. This excludes season-opener games whose adjusted-EPA and some QB/coach features are undefined, so the sweep cannot speak to Week 1.
- Win matched rows: 5583 train of 6407, 797 holdout of 854.
- Total matched rows: 5594 train of 6421, 798 holdout of 855.
- Hyperparameters: each step runs its own training-only search (production grids, budgets and seeded combos); frozen, then refit expanding through each holdout season. Trees also rerun with seeds [42, 7, 123]; 5 placebo (random-noise) draws per batch; a fixed baseline-hyperparameter reading.
- Win bar: Brier improvement >= 0.002, bootstrap lower bound > 0, >= 2 of 3 seasons improved, ECE worsening <= 0.01, log loss not worse.
- Total bar: MAE improvement >= 0.09, bootstrap lower bound > 0, >= 2 of 3 seasons, RMSE not worse, bias shift <= 0.25.
- A pass must also exceed the noise floor: the larger of the largest placebo improvement and the seed range of the batch's improvement.
- Very short EPA windows (1, 2) leave some rates undefined; those columns are imputed with training medians so matched games stay identical.
- The Elo reference is an `ELO_DIFF`-only logistic; the simulated Elo model is not re-run.
- Comparisons made: 25 (batch x family). Holm-adjusted p-values are listed below; the holdout was also used earlier for champion selection.
