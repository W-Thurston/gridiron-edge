# Phase A feature selection - 2026-09-30

Stage 2 of the feature sweep (`PLAN.md`): each model selects its own columns from the wired pool on training rows only, with an in-procedure placebo control. Improvement is positive when the subset is better than the reference (Brier for Win, MAE for Total). A subset is non-inferior when the lower end of its 90% paired-bootstrap interval is above minus the margin. Generated by `gridiron evaluate feature-selection`; a dated record, not an input to any pipeline.

- Early selection: matched rows before the 2013 season, scored walk-forward on 2013 onward (never seen by that selection), fixed hyperparameters from the full-set search shared by all arms.
- Final selection: all matched pre-holdout rows (the deployable subset), confirmed once on the holdout.
