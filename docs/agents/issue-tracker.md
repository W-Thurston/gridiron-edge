# Issue tracker: none

This repo does not use GitHub Issues. Never create, edit, label, comment
on, or close issues, and never use `gh issue` or `gh api` for issue work.

- Future work, deferred bugs, and known limitations live in ROADMAP.md.
- The active implementation unit lives in PLAN.md.
- When a skill says "publish to the issue tracker", propose the ROADMAP.md
  addition in chat and wait.
- When a skill says "fetch the relevant ticket" or needs a spec to review
  against, read the active unit in PLAN.md (goal, tests, acceptance).
- /wayfinder and /triage are not used in this repo.
